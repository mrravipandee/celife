# THE DCO Project

This is a freelance website project for **THE DCO**.
It helps show luxury hospitality work online and collect customer enquiries in one place.

## What this project does

- Shows services and project/case study content
- Lets visitors send enquiries through a contact form
- Gives the team a private admin area to manage content

## Who this is for

- Business owner
- Team members who update website content
- Customers who want to contact the business

## Quick start (for developer)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Add your environment values in `.env` (MongoDB URL, site URL, auth secret).
3. Run the project:
   ```bash
   npm run dev
   ```
4. Open:
   `http://localhost:3000`

## Useful commands

- `npm run dev` → start project
- `npm run lint` → check code style
- `npm run build` → build for production
